### Introduction
When you write an English essay, the app performs grammar checks, detects grammatical errors, and provides statistics. <br/>
This app was developed to help identify common grammatical mistakes and improve English writing skills.

### Key Features
- Firebase Google OAuth login
- English grammar error detection using AI models
- Store related information in Firestore and visualize statistics with graphs
